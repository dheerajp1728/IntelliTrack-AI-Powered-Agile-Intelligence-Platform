# Documentation Index

This folder contains the technical documentation for IntelliTrack.

## Files

1. `CODE_DOCUMENTATION.md`
   - architecture and module-level implementation details
   - backend/frontend/AI service design and extension guide

2. `TEST_DOCUMENTATION.md`
   - testing strategy, commands, and release test criteria
   - performance and security verification workflow

3. `SECURITY_DOCUMENTATION.md`
   - threat model, implemented controls, and security release checklist

4. `CLOUD_DOCUMENTATION.md`
   - AWS runtime architecture, build/deploy flow, and operational checks

## Documentation Standards

When updating this project, keep docs aligned to code changes:

1. update affected technical docs in the same pull request
2. avoid marketing language; document implementation facts
3. include executable commands where relevant
4. keep paths and file names current
